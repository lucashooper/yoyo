# Yoyo — Language App

Monorepo for the Yoyo language learning project.

## Nobi (Mobile)

The **Nobi** Expo React Native app lives in [`mobile/`](mobile/). See [mobile/README.md](mobile/README.md) for full setup.

### Quick start

```bash
git clone https://github.com/lucashooper/yoyo.git
cd yoyo/mobile
cp .env.example .env.local
# Edit .env.local with your API keys (never commit this file)
npm install
npm start
```

Scan the QR code with **Expo Go** on your phone, or press `i` / `a` for simulators.
